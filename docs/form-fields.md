# Launch submission questionnaire (all fields seen across ~60 directories)

Fill this once per product before submitting; every platform then becomes copy-paste. Constraints list the limits seen across platforms — prepare for the strictest.

## 1. 账号与个人资料（登录后的 onboarding）

| # | 问题 | 常见限制 / 说明 |
|---|---|---|
| 1.1 | 登录邮箱 / Google 账号 | 多数用 Google 登录；有的要邮件 magic link |
| 1.2 | 显示名 Full name / First & Last name | |
| 1.3 | 用户名 Username / handle | |
| 1.4 | 个人 Headline（职位一句话） | 必填较多 |
| 1.5 | 个人简介 About / Bio | ≤500 |
| 1.6 | 作者 X / Twitter | 有的要 handle，有的要完整 URL |
| 1.7 | LinkedIn / Threads / 个人网站 | 可选 |
| 1.8 | 所在国家 / 地区 | 可选 |
| 1.9 | 头像 | 512×512，≤2MB |
| 1.10 | 手机号 | 可选（Maidensail） |
| 1.11 | "你从哪里知道我们" | 下拉 + Other 文本 |
| 1.12 | 身份 / 目标 / 兴趣（社区型平台的偏好问卷） | 多选（Commune） |

## 2. 产品基本信息

| # | 问题 | 常见限制 / 说明 |
|---|---|---|
| 2.1 | 产品名 | 12 / 24 / 25 / 40 / 60 字符 |
| 2.2 | 产品 slug / handle | 小写、连字符；提交后多不可改 |
| 2.3 | 官网 URL | 提交后多不可改；只填正式站，不填跟踪链接 |
| 2.4 | 附加链接 / Affiliate URL | 可选 |
| 2.5 | App Store / Google Play / 插件商店链接 | 移动端或插件才填 |
| 2.6 | Tagline 一句话卖点 | 最短 34–40，常见 60 / 80 / 90 / 92 / 100 / 130 / 160 / 200 / 250 |
| 2.7 | One-liner / 卡片摘要 | 20–120 或 ≤150 / 160（SEO meta 常要 120–170） |
| 2.8 | 短描述 | ≈256 / 300 |
| 2.9 | 长描述 / Introduction / About | 下限 40 / 300 / 500；上限 600 / 1000 / 1500 / 2000 / 3000 / 5000 / 10000；Markdown 或富文本 |
| 2.10 | Who is it for（目标用户一句话） | ≥10 字 |
| 2.11 | Problem / Solution / What makes it unique | 可选，各一段 |
| 2.12 | Key features | 最多 6 条，每条一句 |
| 2.13 | Use cases | 最多 3–8 条 |
| 2.14 | FAQ（问 + 答） | 最多 10 组 |
| 2.15 | 替代品 / 竞品 Alternatives | 最多 5–8 个，必须是真实产品 |
| 2.16 | 产品类型 | Software / Digital product / SaaS / Tool / n8n workflow |
| 2.17 | 是否开源 / 是否 vibe coded / 是否在出售产品 | 是/否 |
| 2.18 | 创立年份 | |
| 2.19 | 产品阶段 Stage | Idea / Pre-revenue / Revenue / Profitable |
| 2.20 | 意向 Intent | 接受收购 / 融资中 / 都不是 |
| 2.21 | 自报数据 Traction / MRR | 可选，"self-reported" |
| 2.22 | 是否 NSFW / 是否涉及加密货币、赌博等 | 勾选声明 |
| 2.23 | 特色问题（个别平台专属） | 例：ConfettiSaaS 问"彩带庆祝动画在哪里出现" |

## 3. 分类与发现

| # | 问题 | 常见限制 / 说明 |
|---|---|---|
| 3.1 | 主分类 Category | 单选或 1–4 个；第一个常是主分类 |
| 3.2 | 子分类 | 最多 3–4 个 |
| 3.3 | 标签 Tags | 3–5 个 |
| 3.4 | SEO 关键词 | 最多 10 个 |
| 3.5 | 目标受众 Target audience / 适合的职业 | 多选（Submit AI Tools 必填） |
| 3.6 | 平台 Platforms | Web / iOS / Android / API / CLI / Desktop / Chrome Extension，只选真实支持的 |
| 3.7 | 技术栈 Tech stack | 部分平台必填，最多 5–8 个 |

## 4. 定价

| # | 问题 | 常见限制 / 说明 |
|---|---|---|
| 4.1 | 定价模式 | Free / Freemium / Paid / Subscription / One-time / Free trial / Contact sales |
| 4.2 | 起步价 / 最低付费价 | 美元 / 月 |
| 4.3 | 套餐列表（名称、价格、周期、2–5 条功能） | 最多 4 个 |
| 4.4 | 计费周期 | Monthly / Annual / Usage-based |
| 4.5 | 免费试用天数 | 0 表示无试用 |
| 4.6 | 数据可导出吗 | 全部 / 部分 / 不可 |
| 4.7 | 优惠码 Deal / Promo code | 可选 |

## 5. 素材

| # | 素材 | 常见限制 |
|---|---|---|
| 5.1 | 方形 Logo / Icon | 1:1，≥240 / 256 / 400 / 512 px；≤200KB / 500KB / 1MB / 2MB；PNG/JPG/WebP/SVG |
| 5.2 | 封面 / 主图 Cover | 16:9 或 1.91:1（1200×630、1280×720），≤1MB |
| 5.3 | 宽幅横幅 | 6:1（2400×400，Startup Fast） |
| 5.4 | 产品截图 Screenshots | 1–10 张；1280×800 / 1600 / 1920×1080；单张 ≤500KB–5MB |
| 5.5 | 演示视频 | YouTube / Loom / Vimeo 链接，可选 |
| 5.6 | Logo / 截图的 URL 版本 | 有的平台只收 URL |

|---|---|---|

## 7. 发布设置

| # | 问题 | 常见限制 / 说明 |
|---|---|---|
| 7.1 | 发布方案 | Free / 各种付费档；付费档常默认勾选，要手动取消 |
| 7.2 | 发布日期 / 周 | 免费档常在 2 周到 12 个月后；有"随机日期"选项 |
| 7.3 | 首评 Maker comment | 200 / 500 / 1000 字 |
| 7.4 | 点赞后感谢语 Thank-you note | ≤280 |
| 7.5 | 是否同时上架姊妹站 | 例：Launch Llama 默认勾选 Launch MCP |
| 7.6 | 同意条款 / 内容政策 / 拥有发布权 | 必勾 |
| 7.7 | 订阅营销邮件 / newsletter | 一般可选；Submit AI Tools 免费档必勾 |
| 7.8 | 给提交流程打分 | 可选（Launch List） |

## 8. Badge 与外链验证

| # | 问题 | 说明 |
|---|---|---|
| 8.1 | badge 放在哪个页面 | 首页或全站 footer；要服务端渲染 |
| 8.2 | 用于验证的页面 URL | 多数填首页 |
| 8.3 | badge 样式 | Light / Dark |
| 8.4 | 特殊链接要求 | 不能带 rel、只能 rel="noopener"、必须指向专属页、保留 ?ref= |
| 8.5 | 官网 Domain Rating | 部分免费档要求 DR ≥ 10 / 20 |
